# Guardmarly evidence benchmark

Reproducible, self-contained measurement of what the scanner actually does.
Every number in [`results/EVIDENCE.md`](results/EVIDENCE.md) is produced by these
scripts at run time — none of it is transcribed from documentation, a marketing
page, or a previous run.

## Why this exists

A SAST tool's credibility rests on two claims: *it finds real bugs* and *it does
not cry wolf*. Both are measurable, and both were previously unmeasured. This
harness measures them on corpora that require **no network access and no
credentials**, so a reviewer can reproduce the results on any machine with the
repository checked out.

## Layout

```text
benchmarks/
├── build_corpus.py      # generates corpus/ + ground_truth.json (ground truth lives here)
├── corpus/              # 36 vulnerable + 19 clean fixtures, 5 languages (generated)
├── ground_truth.json    # corpus-relative path -> expected CWE set (generated)
├── run_benchmark.py     # the runner
└── results/             # *.json raw measurements + EVIDENCE.md write-up
```

## Corpora

| Corpus | Source | Needs network? | What it measures |
| --- | --- | --- | --- |
| **Labelled** (55 files, 14 CWE classes) | generated by `build_corpus.py` | no | precision, recall |
| **Python stdlib core** | ships with the interpreter (`sysconfig`) | no | false positives on peer-reviewed code |
| **Flask / Express / Gin** | `.corpora/*_fresh` if present | no | false positives on audited frameworks |
| **Django** | `.corpora/django_fresh` (opt-in) | no | throughput at scale |

The labelled corpus pairs each vulnerable snippet with a canonically *safe*
twin that looks superficially similar (parameterised query vs concatenation,
`execFile` array vs `exec` string, owner-scoped lookup vs bare lookup). A
pattern-only matcher cannot pass by memorising callee names.

## Running

```bash
python benchmarks/build_corpus.py                 # (re)generate fixtures
python benchmarks/run_benchmark.py labelled       # precision / recall
python benchmarks/run_benchmark.py clean          # noise on trusted code
python benchmarks/run_benchmark.py throughput     # LOC/s
python benchmarks/run_benchmark.py headtohead     # vs Bandit + Semgrep OSS
python benchmarks/run_benchmark.py all            # everything
python benchmarks/make_evidence.py                # regenerate results/EVIDENCE.md
```

Environment overrides:

| Variable | Default | Purpose |
| --- | --- | --- |
| `GM_BENCH_STDLIB_FILES` | `400` | core-stdlib files to sample (largest first, deterministic) |
| `GM_BENCH_DJANGO` | unset | set to `1` to include the ~523 kLOC Django tree |
| `BANDIT_EXE` | `…\X\.venv\Scripts\bandit.exe` | competitor path |
| `SEMGREP_EXE` | `…\X\.venv\Scripts\semgrep.exe` | competitor path |

Missing competitors degrade gracefully — the head-to-head simply reports the
tools it could find.

## Ground-truth discipline

* A positive is *detected* only if the scan reports the declared CWE on that
  file. Reporting an unrelated CWE there is a miss, not a partial credit.
* Any security finding on a negative is a false positive, full stop.
* Findings are counted post-triage, because that is what a user is shown.
  Triage's effect is measured separately and reported, never assumed.

## Notes

* `corpus/` is excluded from `ruff` (`pyproject.toml`) — it is scanner *input*,
  deliberately containing SQL injection and shell injection.
* Fixtures avoid pytest's `tmp_path` (its name contains `test_`, which is
  itself a triage pattern) and clean up only the exact directory they created.
